Kascii stands on two projects that proved the idea on the web, and sits next to a sibling for dithering.

- **[asciicn](https://asciicn.dev)** (MIT) is a React and shadcn ASCII engine: tone to glyph over ten charsets, five color modes, a WebGL glyph shader, a Canvas grid, image, video and webcam sampling, and export to text, ANSI, SVG and PNG. Kascii borrows its vocabulary and the idea of ordering ramps by measured ink coverage.
- **[ascii.rest](https://github.com/bas3line/ascii)** (MIT) is a catalogue of about 240 animated ASCII pieces with a kit for building more, plus banner and image tools. Kascii borrows the piece contract: a size, a frame rate, a still frame for reduced motion, and a function of time. Where a gallery piece is a port of a specific ascii.rest piece, its entry says so, and the original license is kept in `THIRD_PARTY_NOTICES`.
- **[Stipple](https://github.com/jantursky/stipple)** is the same author's dithered-UI library for Compose Multiplatform. It turns tone into ink and paper dots, Kascii turns it into glyphs. They share an architecture and can be used together, see [using it with Stipple](/guides/using-with-stipple).

On Compose Multiplatform itself, a search of klibs.io, GitHub and Maven Central found no library for ASCII or text-mode effects. The nearest are:

- [ShaderX](https://github.com/Debanshu777/ShaderX), a shader library whose sample app has an ASCII camera built from a single dither shader, not a glyph atlas.
- [Kasciffy](https://github.com/gmitch215/kasciffy), a Kotlin Multiplatform image and video to ASCII converter without Compose rendering.
- [HypnoticCanvas](https://github.com/mikepenz/HypnoticCanvas), a multiplatform shader library whose texture plumbing is a useful reference.

What Kascii adds is a glyph engine that is a Compose citizen: modifiers, a real accessible component set, a pause-offscreen and reduced-motion clock, a choice of renderers including selectable text, and an animated gallery, all from common code.
